# Raycast Extensions

A collection of personal Raycast extensions.

## Extensions

### iMessage
Send iMessages directly from Raycast, with AI chat support.

#### Features
- Send iMessages to contacts directly from Raycast
- AI tool support — use `@imessage` in Raycast AI chat to send messages conversationally
- Contact picker populated from your Contacts app
- Contacts cached locally for fast lookup
- Confirmation prompt before sending messages

### Installation
```bash
git clone https://github.com/george-593/raycast
cd raycast/extensions/ai-imessage
npm install
npm run build
```
